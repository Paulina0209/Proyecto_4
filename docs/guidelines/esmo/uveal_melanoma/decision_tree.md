# Árbol de decisión clínico: Melanoma uveal (UM)

```text
UM sospechada o confirmada
  |
  +-- Diagnóstico clínico (oftalmoscopia, fotografía de fondo, ecografía ocular)
  |    +-- Diagnóstico incierto -> considerar biopsia (discutir riesgos con el paciente) [II, A]
  |    +-- Localización en cuerpo ciliar -> biomicroscopía US de alta frecuencia [II, A]
  |
  +-- Estadificación y pronóstico
  |    +-- Imagen ocular + RM de órbita (extensión local/extraocular)
  |    +-- Clasificación AJCC 8ª edición
  |    +-- Cribado de metástasis a distancia (US/RM hepática +/- PET-CT o TC TAP)
  |    +-- Si hay material suficiente: perfil molecular (cr3/6/8, GEP, BAP1/SF3B1/EIF1AX, IHC BAP1/PRAME) [III, B]
  |    +-- HLA-A*02:01: obligatorio si metástasis [I, A]; considerar si localizada (acceso a ensayos) [V, B]
  |
  +-- Enfermedad localizada
  |    |
  |    +-- ¿Conservación ocular posible?
  |    |    |
  |    |    +-- Sí
  |    |    |    +-- Informar riesgos de RT (efectos adversos, pérdida visual) [III, A]
  |    |    |    +-- RT: braquiterapia o PBR (preferidas) [III, A]; SRT si no disponibles [IV, B]
  |    |    |    +-- Anti-VEGF intravítreo si neovascularización [IV, B]
  |    |    |    +-- Seguimiento oftalmológico cada 6 meses (2-5a), luego anual [II, A]
  |    |    |         +-- Estabilidad incierta -> acortar intervalo [II, A]
  |    |    |    +-- Recurrencia local -> TTT, re-RT o enucleación (según caso) [V, B]
  |    |    |
  |    |    +-- No (tumor grande / extensión extraescleral)
  |    |         +-- Enucleación [II, A]
  |    |         +-- Alto riesgo (márgenes+/extensión) -> RT externa adyuvante [II, B]
  |    |
  |    +-- Riesgo de metástasis (genómico/clínico)
  |    |    +-- Alto riesgo -> ofrecer ensayo clínico adyuvante si disponible [II, A]
  |    |
  |    +-- Vigilancia adaptada al riesgo
  |         +-- Bajo riesgo (≤T2a, sin alteración cr3/8, GEP clase 1)
  |         |    -> ecografía hepática cada 6-12 meses, ≥5 años [III, A]
  |         +-- Alto riesgo (T2b/c/d o ≥T3, alteración cr3/8, GEP clase 2)
  |              -> RM hepática cada 4-6 meses, ≥10 años [III, A]
  |
  +-- Enfermedad metastásica
       |
       +-- Estadificación: RM hepática, TC TAP, pruebas hepáticas, LDH, +/- PET-CT
       +-- Estado HLA-A*02:01
       |
       +-- ¿Metástasis confinadas al hígado?
            |
            +-- Sí
            |    |
            |    +-- Oligometastásica
            |    |    +-- Cirugía (metastasectomía) [IV, B]
            |    |    +-- Ablación térmica (RFA/MWA) o crioablación [IV, B]
            |    |    +-- SRT si no elegible para cirugía/ablación [IV, B]
            |    |    (ponderar riesgo-beneficio en comité multidisciplinar [IV, B];
            |    |     discutir tebentafusp antes de tto local dirigido al hígado)
            |    |
            |    +-- Multifocal
            |         +-- Tratamiento regional: PHP, IHP, HAI, TACE o TARE [II, B]
            |         +-- + tratamiento sistémico según estado HLA
            |
            +-- No (extrahepáticas y/o hepáticas)
                 |
                 +-- HLA-A*02:01 positivo
                 |    +-- Tebentafusp, primera línea [I, A; MCBS 3]
                 |         +-- Progresión (PD) ->
                 |              tratamiento dirigido al hígado [V, B]
                 |              inmunoterapia anti-PD-1 [V, B]
                 |              ensayo clínico [V, B]
                 |
                 +-- HLA-A*02:01 negativo
                      +-- Tratamiento dirigido al hígado [V, B]
                      +-- Inmunoterapia anti-PD-1 [V, B]
                      +-- Ensayo clínico [V, B]

Notas transversales (aplican a cualquier rama):
  - Biopsia líquida general: uso experimental, no recomendada fuera de investigación [III, D]
  - Calidad de vida: evaluación regular con herramienta específica (EORTC QLQ-OPT30) [III, A]
  - Seguimiento y decisiones siempre en centro de referencia / comité multidisciplinar [III, A]
```
